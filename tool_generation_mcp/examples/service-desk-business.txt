Harbor Stay runs short-term apartment bookings. After booking, each customer receives a confirmation that shows a booking reference. During a stay, customers report problems (for example cleaning or maintenance issues) by filing a service request for their booking with a category and a short description of the problem. We want an assistant tool that lets a customer look up their booking with the reference from the confirmation and file a service request for it. Customers must only be able to file requests for bookings they hold. The tool must not cancel or change bookings.
