How it works

{{ m.steps("") }}
  1. Connect your system: upload or fetch its OpenAPI description. Team C lists what the API can do; nothing is called.
  2. Get tools: describe a tool in plain language, or ask Team C to suggest some. The AI turns them into proposals.
  3. Review and approve: answer the proposal's questions, check the answers, confirm who may use it, then approve it to build.
  4. Build and test: set up access enforcement, build the tool and run sandbox tests against test accounts.
  5. Publish (test only): expose the tested tool to a local sandbox MCP server. Production is never touched.
